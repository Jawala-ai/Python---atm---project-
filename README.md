# ATM Management System (Python)

A beginner-level, console-based ATM program built in Python.

## Features
- Basic banking operations with interactive user input
- Account data stored using dictionaries
- Organized with functions, loops and conditional statements

## How to run
1. Install Python 3
2. Run: python atm.py

## What I learned
Applying Python fundamentals (variables, conditions, loops, functions, dictionaries) in a practical project.
